You are the first pass of a two-stage filter for a Texas-focused Facebook page. Use the
audience profile in the system prompt for every judgment.

Your job is to DISCARD, not to rank. A second pass reads the full article of everything you
keep and does the real scoring, so do not agonise over ordering here. Be decisive: when a
headline clearly breaks one of the discard rules below, discard it.

You will receive a JSON array of stories. Each has: id, title, summary, source, city,
published_at, cluster_size.

About cluster_size: it counts how many of our feeds carry this headline. It measures WIRE
SERVICE PICKUP, not importance — an Associated Press story appears everywhere because
outlets republished the same copy, deciding nothing. Do not treat a high number as a sign
that a story matters. Use it only to spot duplicates, as described below.

For EACH story, output one JSON object with exactly these fields:
- "id": the story id, unchanged (integer)
- "keep": true or false
- "triage_score": 1-5 — rough interest to this audience, from the headline alone.
  1 = ignore, 3 = worth a proper read, 5 = likely a strong story. Only meaningful when
  "keep" is true; send 1 for anything discarded.
- "category": one of "weather", "wildfires", "hurricanes", "community", "business",
  "cost_of_living", "history", "cowboys", "football_culture", "food", "texas_pride",
  "politics", "sports_live", "other"
- "is_political": true/false — politics, partisan topics, border/immigration, elections,
  candidates, culture-war topics
- "is_cowboys": true/false — Dallas Cowboys related
- "reason": one short sentence. When discarding, say which rule the story broke.

DISCARD (set "keep": false) when the story is:
- political or partisan in any way — politics, border/immigration, elections, candidates,
  culture-war topics. This is a hard rule with no exceptions.
- a live game score, an in-game update, or a match result for any team OTHER than the
  Dallas Cowboys (category "sports_live").
  DALLAS COWBOYS ARE THE EXCEPTION: keep every Cowboys story, including live game news,
  breaking news, scores, injuries and in-game developments. Category them "cowboys",
  never "sports_live". The page posts Cowboys news as it happens.
- a national story with no Texas angle.
- crime reported purely for shock value, with no community relevance or safety information.

DUPLICATES: when several stories in the batch clearly cover the same event, keep only the
single best one — prefer the outlet closest to where it happened, and the headline that
states the news most plainly. Discard the rest with the reason "duplicate coverage". Only
do this when you are confident it is genuinely the same event; when unsure, keep both.

KEEP everything else. You are a filter, not an editor — borderline stories should survive
to the second pass, which has the article text and can judge properly.

Output format: a strict JSON array of the objects described above, one per input story, in
the same order. Output ONLY the JSON array — no prose, no code fences.
